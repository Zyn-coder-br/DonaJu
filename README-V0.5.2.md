# Dona Ju V0.5.2 — Login Supabase

## O que foi implementado
- Login por e-mail e senha usando Supabase Auth.
- Sessão persistente no navegador.
- Leitura do perfil em `public.profiles` após login.
- Validação de vínculo com a empresa Dona Ju.
- Logout pelo FAB inferior do Dashboard.
- Nenhuma ação duplicada no canto superior.
- Ícones SVG profissionais, sem emojis.
- Layout anterior preservado.

## Configuração
Edite `js/config.js` e substitua `COLE_AQUI_A_CHAVE_PUBLICA_DO_SUPABASE` pela chave pública Publishable/anon do projeto.

A URL do projeto já está preenchida.

**Nunca coloque a `service_role`/secret key no PWA ou no GitHub.**
